# Academic Compass — Student Academic Management System

A React + Vite college project for managing learners, marks, attendance, performance insights, and study tasks.

## Tech
- React 18
- React Router DOM 6
- JavaScript / JSX
- CSS only
- Browser localStorage
- No backend or database

## Pages
1. Overview
2. Learner Directory
3. Marks & Gradebook
4. Attendance Tracker
5. Performance Insights
6. Study Planner (extra page)

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Data storage
The app uses these localStorage keys:
- `ac_learners`
- `ac_marks`
- `ac_attendance`
- `ac_plans`

The initial sample data is intentionally included so the project is not empty on first launch. Records remain after a refresh.
