# TaskNest — Focus Workspace

A complete React + Vite task management project with a distinctive productivity-studio theme.

## Run
1. Open this folder in VS Code.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local Vite URL.

## Features
- Dashboard / Workspace
- Add and edit tasks
- My Tasks search and filters
- Monthly calendar
- Dynamic statistics
- Settings with persistent dark mode
- localStorage-only task persistence
- Responsive desktop/mobile navigation

## Storage
Tasks use `tasknest_tasks_v2`.
Settings use `tasknest_settings_v2`.

No backend or database is required.
